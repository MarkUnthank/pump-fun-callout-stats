# Security

Please report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/MarkUnthank/pump-fun-callout-stats/security/advisories/new).

Include the extension version, a clear description, reproduction steps and the impact you observed. Do not include private keys, credentials or another person's private data. Please keep exploit details out of public issues until we have investigated.

This repository contains the browser extension. Reports about the hosted stats service can use the same private reporting channel.
